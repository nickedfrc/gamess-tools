# gamess-tools

Two small utilities for converting between GAMESS(US) and Molden files.

| Script | Purpose |
| --- | --- |
| `dat2molden` | GAMESS text punch file (`.dat`) + `.gms` -> Molden file |
| `molden2gmsinp` | Molden file -> GAMESS input file (`.inp`, with `$DATA` / `$VEC`) |

Both are single-file Python 3 scripts built only on the standard library, with
no third-party dependencies. `chmod +x` and run them directly.

> **User-defined route sections**
>
> `molden2gmsinp` used to hard-code a fixed set of GAMESS program blocks in the
> source. Those have been **removed entirely, and the default is now empty**:
> every route section is supplied by the user on the command line via `--set`.
> If you pass no `--set`, no route section is written at all. Only `$DATA` and
> `$VEC` are still generated automatically, because they follow from the
> molecular geometry and the orbital coefficients.

---

## dat2molden

A GAMESS punch file already contains the basis set and the orbital
coefficients; the atomic coordinates are read from the `.gms` file.

```
dat2molden <jobname> [options]
```

### Options

| Option | Description |
| --- | --- |
| `-o, --output FILE` | Output Molden file. Default: `<jobname>.molden` |
| `--title TEXT` | `[Title]` of the Molden file. Default: `Generated by dat2molden from <jobname>` |
| `--charge Q` | Total charge, used to derive the default occupations. Default: `0` |
| `--mult M` | Spin multiplicity, used to derive the default occupations. Default: `1` (closed shell, 2 electrons per MO) |
| `--nocc N` | Number of doubly occupied orbitals; overrides the value derived from `--charge`/`--mult` |
| `--occ 'O1 O2 ...'` | Explicit per-orbital occupations, 1-based, e.g. `--occ '2 2 2 1 0'`. Overrides `--nocc` |
| `-h, --help` | Show help |

`<jobname>` may be given with or without the `.gms` / `.dat` extension, and may
include a directory, e.g. `runs/rastest`.

### Examples

```bash
dat2molden rastest                        # reads rastest.gms + rastest.dat
dat2molden rastest -o out/rastest.molden  # explicit output path
dat2molden rastest --charge -1 --mult 2   # open-shell anion
dat2molden rastest --occ '2 2 2 1 0 0'    # hand-picked occupations
```

### Output

- `[Atoms] Angs` -- from the BOHR coordinate block in `.gms`, converted to Angstrom
- `[GTO]` -- the raw basis exponents/coefficients from `.dat`
- `[MO]` -- the `$VEC` section from `.dat`; occupations follow the options above

### Known limitation

`dat2molden` needs the punch file to **actually print the raw basis data**
(a shell header such as `S 2` followed by exponent/coefficient lines). If the
file only records a built-in basis keyword such as `N21 3` or `STO 2`, the raw
exponents and coefficients are simply not present and the `[GTO]` section
cannot be reconstructed. In that case, have GAMESS print the basis into the
punch file, or obtain the basis from another source.

## molden2gmsinp

Writes the atoms and contracted basis set from the Molden file into `$DATA`,
and the orbital coefficients into `$VEC`. All GAMESS route sections come from
the command line.

```
molden2gmsinp [options] <molden_file> <output_inp>
```

### Options

| Option | Description |
| --- | --- |
| `--set 'SECTION PARAMS'` | Append/override a GAMESS program block; repeatable. `SECTION` starts with `$`; the `$END` terminator is optional |
| `--guess` | Emit `$GUESS GUESS=MOREAD NORB=<n_mo>`, where `n_mo` is the number of MOs actually written to `$VEC` |
| `--basis 'PARAMS'` | Emit an extra `$BASIS PARAMS` block (e.g. for a test run that should not read the basis from `$DATA`) |
| `--charge C` | Total charge; written as `ICHARG=C` on the `$DATA` title line when non-zero |
| `--mult M` | Spin multiplicity; written as `MULT=M` on the `$DATA` title line when not 1 |
| `--title TEXT` | Second line of `$DATA`. Default: `Molden import` |
| `--swap A B` | Swap MOs A and B (1-based); repeatable |
| `-h, --help` | Show help |

### Values filled in automatically

- If a `$SUBSHL` block is present and `NVIRTS` was not given explicitly, the
  actual number of MOs is filled in.
- With `--guess`, if `NORB` was not given explicitly in `$GUESS`, the actual
  number of MOs is filled in.

Both only apply when the corresponding block is **already present** -- the script
never creates a `$SUBSHL` block out of nothing. If you write `NVIRTS=` or
`NORB=` yourself via `--set`, your value is kept and never overwritten.

### Examples

**RHF single point:**

```bash
molden2gmsinp mol.molden rhf.inp \
    --set '$CONTRL SCFTYP=RHF RUNTYP=ENERGY' \
    --set '$SYSTEM MWORDS=1000' \
    --guess
```

**DFT, reading the basis from `$DATA`:**

```bash
molden2gmsinp mol.molden dft.inp \
    --set '$CONTRL SCFTYP=RHF DFTTYP=B3LYP RUNTYP=ENERGY' \
    --set '$SYSTEM MWORDS=2000'
```

**Open-shell anion with a different basis:**

```bash
molden2gmsinp mol.molden uhf.inp \
    --set '$CONTRL SCFTYP=UHF RUNTYP=ENERGY' \
    --basis 'GBASIS=N31 NGAUSS=6 NDFUNC=1' \
    --charge -1 --mult 2 --title 'anion doublet'
```

**Swapping orbitals** (e.g. to correct an orbital ordering):

```bash
molden2gmsinp --swap 32 33 --swap 45 46 mol.molden out.inp \
    --set '$CONTRL SCFTYP=ROHF RUNTYP=ENERGY'
```

**Several keywords in one block** -- repeated `--set` calls for the same section
are merged, and long lines wrap at column 72 with a 6-space continuation
indent:

```bash
molden2gmsinp mol.molden out.inp \
    --set '$CONTRL SCFTYP=RHF RUNTYP=ENERGY' \
    --set '$SYSTEM MWORDS=8000 PARALLEL=.TRUE. MEMORY=2000000'
```

### Output layout

Route sections come first, wrapped at column 72:

```
 $CONTRL SCFTYP=RHF DFTTYP=B3LYP RUNTYP=ENERGY $END
 $SYSTEM MWORDS=8000 $END
 $GUESS NORB=34 GUESS=MOREAD $END
 $DATA
Molden import
C1
OXYGEN                    8.0        0.000000        0.000000        0.000000
 S   2
   1      31.316600000000       0.243991000000
   ...
 $END
 $VEC
 1  1 3.75354288E-01 5.11648917E-02 ...
 $END
```

Element names are mapped from the nuclear charge in `[Atoms]` to the full names
GAMESS expects (`O` -> `OXYGEN`). If the charge column is unusable the script
falls back to the atomic number, then to the upper-cased element symbol.

## Typical workflow

```
.gms + .dat  --[dat2molden]-->  .molden
                                   |
                                   |  inspect / edit / rebasis in any
                                   |  Molden-aware program
                                   v
                             [molden2gmsinp]
                                   |  --set supplies the route sections
                                   v
                                 .inp
```

Feeding the Molden file produced by `dat2molden` back into `molden2gmsinp`
round-trips the basis set and orbital coefficients unchanged (measured: 13
shells, 31 basis functions, 34 MOs, reproduced exactly).

## Requirements

- Python 3.6+
- Standard library only (`sys`, `os`, `re`, `math`)
- Plain-text input and output, no external dependencies
