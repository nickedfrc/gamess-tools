# gamess-tools

两个用于 GAMESS(US) 与 Molden 之间互相转换的小工具。

| 脚本 | 作用 |
| --- | --- |
| `dat2molden` | GAMESS 文本 punch 文件（`.dat`）+ `.gms` → Molden 文件 |
| `molden2gmsinp` | Molden 文件 → GAMESS 输入文件（`.inp`，含 `$DATA` / `$VEC`） |

两个脚本都是单文件 Python 3，只用标准库，无第三方依赖。建议 `chmod +x` 后直接运行。

> **关于"非 general 的输入文件部分"**
>
> `molden2gmsinp` 早期版本把整套 RASS/FCSCF 路线段（`$CONTRL SCFTYP=RASS ...`、
> `$SUBSHL`、`$FCOPT`、`$FCCVG`、`$RDISCT`、`$POSTFC`、`$MATCAL`、`$FCDICT`、
> `$FCLSCT`、`$FCLVCT`、`$SYSTEM`、`$GUESS`）硬编码在源码里。现在**这些内容全部删除，
> 默认为空**，改由用户在命令行通过 `--set` 自行提供；不指定就什么都不写。
> 只有 `$DATA` / `$VEC` 这两个由分子几何和轨道系数决定的部分仍然自动生成。

---

## dat2molden

GAMESS punch 文件里已经含有基组和轨道系数，原子坐标则从 `.gms` 里读。

```
dat2molden <jobname> [options]
```

### 选项

| 选项 | 说明 |
| --- | --- |
| `-o, --output FILE` | 输出 Molden 文件名。默认 `<jobname>.molden` |
| `--title TEXT` | Molden 文件的 `[Title]`。默认 `Generated by dat2molden from <jobname>` |
| `--charge Q` | 体系总电荷，用于推算默认占据数。默认 `0` |
| `--mult M` | 自旋多重度，用于推算默认占据数。默认 `1`（闭壳层，每个轨道 2 电子） |
| `--nocc N` | 指定双占据轨道数，覆盖由 `--charge/--mult` 推出的值 |
| `--occ 'O1 O2 ...'` | 逐轨道显式指定占据数（从 1 开始），如 `--occ '2 2 2 1 0'`。覆盖 `--nocc` |
| `-h, --help` | 显示帮助 |

`<jobname>` 可以带或不带 `.gms` / `.dat` 后缀，也可以带目录，如 `runs/rastest`。

### 例子

```bash
dat2molden rastest                        # 读 rastest.gms + rastest.dat
dat2molden rastest -o out/rastest.molden  # 指定输出
dat2molden rastest --charge -1 --mult 2   # 开壳层阴离子
dat2molden rastest --occ '2 2 2 1 0 0'    # 手工指定占据
```

### 输出内容

- `[Atoms] Angs` —— 来自 `.gms` 的 BOHR 坐标段，转换成 Å
- `[GTO]` —— 来自 `.dat` 的基组原始指数/系数
- `[MO]` —— 来自 `.dat` 的 `$VEC` 段，占据数由上面选项决定

### 已知限制

`dat2molden` 需要 punch 文件里**真正打印出基组原始数据**（形如 `S 2` 后跟
指数/系数行）。如果只写了内建基组关键字（如 `N21 3`、`STO 2`），
文件里没有原始指数和系数，就无法还原 `[GTO]` 段——这种情况下请让
GAMESS 把基组打进 punch 文件，或改用别的基组来源。

## molden2gmsinp

把 Molden 文件里的原子、收缩基组写进 `$DATA`，轨道系数写进 `$VEC`；
所有 GAMESS 路线段由命令行提供。

```
molden2gmsinp [options] <molden_file> <output_inp>
```

### 选项

| 选项 | 说明 |
| --- | --- |
| `--set 'SECTION PARAMS'` | 追加/覆盖一个 GAMESS 程序段，可重复多次。`SECTION` 以 `$` 开头，`$END` 可写可不写 |
| `--guess` | 输出 `$GUESS GUESS=MOREAD NORB=<n_mo>`，`n_mo` 为实际写入 `$VEC` 的轨道数 |
| `--basis 'PARAMS'` | 额外输出一个 `$BASIS PARAMS` 段（例如测试运行时不从 `$DATA` 读基组） |
| `--charge C` | 总电荷，非 0 时以 `ICHARG=C` 写在 `$DATA` 标题行 |
| `--mult M` | 自旋多重度，非 1 时以 `MULT=M` 写在 `$DATA` 标题行 |
| `--title TEXT` | `$DATA` 第 2 行文本。默认 `Molden import` |
| `--swap A B` | 交换第 A 和第 B 个轨道（从 1 开始），可重复多次 |
| `-h, --help` | 显示帮助 |

### 自动填充的数值

- `$SUBSHL` 段存在且未显式给 `NVIRTS` 时，填入实际轨道数
- `--guess` 时，`$GUESS` 段未显式给 `NORB` 时填入实际轨道数

两者都只在**已有该段**的前提下生效，不会凭空创建 `$SUBSHL` 段；
如果你在 `--set` 里自己写了 `NVIRTS=` / `NORB=`，脚本不会覆盖你的值。

### 例子

**RASS / FCSCF 运行**（等价于旧版硬编码的行为，但要什么写什么）：

```bash
molden2gmsinp mol.molden cf.inp \
    --set '$CONTRL SCFTYP=RASS RUNTYP=ENERGY ISPHER=0' \
    --set '$SUBSHL NCORES=2 NHOLES=5 NPARTS=7' \
    --set '$FCOPT BSFTYP=SINGLT' \
    --set '$FCCVG FCDIIS=.F. FCLNS=.F. FCLEV=.F. FCRDIS=.F. FIDIIC=.F.' \
    --set '$RDISCT LRDIS=10 RDISST=1.0E-3 RDISED=1.0E-5 IRDTYP=0 RDICOF=1E2' \
    --set '$POSTFC RCCIS=.TRUE.' \
    --set '$MATCAL TREXP=0 TRLOG=0' \
    --set '$FCDICT MAXLEN=20 LDIIS=5 DIISST=5E-2 DIISED=1E-8 DIIDBG=.F. DIICOF=10 FIXREF=.F.' \
    --set '$FCLSCT LNSED=1E-8 AUTOUV=.T. AUTEXP=.F.' \
    --set '$FCLVCT LVHOLE=0.2D0 LVPART=0.3D0 LVVIRT=0.5D0' \
    --set '$SYSTEM MWORDS=8000' \
    --set '$GUESS GUESS=MOREAD' \
    --guess
```

**普通 RHF 单点**：

```bash
molden2gmsinp mol.molden rhf.inp \
    --set '$CONTRL SCFTYP=RHF RUNTYP=ENERGY' \
    --set '$SYSTEM MWORDS=1000' \
    --guess
```

**开壳层阴离子 + 换基组**：

```bash
molden2gmsinp mol.molden uhf.inp \
    --set '$CONTRL SCFTYP=UHF RUNTYP=ENERGY' \
    --basis 'GBASIS=N31 NGAUSS=6 NDFUNC=1' \
    --charge -1 --mult 2 --title 'anion doublet'
```

**交换轨道**（例如修正轨道顺序）：

```bash
molden2gmsinp --swap 32 33 --swap 45 46 mol.molden cf.inp --set '$CONTRL SCFTYP=RASS'
```

### 输出布局

路线段在最前面，同一段参数过长时按 72 列折行，续行缩进 6 格：

```
 $CONTRL SCFTYP=RASS RUNTYP=ENERGY ISPHER=0 $END
 $SUBSHL NVIRTS=34 NCORES=2 NHOLES=5 NPARTS=7 $END
 $FCDICT MAXLEN=20 LDIIS=5 DIISST=5E-2 DIISED=1E-8 DIIDBG=.F. DIICOF=10
      FIXREF=.F. $END
 $DATA
Molden import
C1
OXYGEN                    8.0        0.000000        0.000000        0.000000
 S   2
   1      31.316600000000       0.243991000000
   ...
 $END
 $VEC
 1  1 3.75354288E-01 5.11648917E-02 ...
 $END
```

元素名按 `[Atoms]` 的核电荷映射成 GAMESS 要求的全名（`O` → `OXYGEN`）；
若核电荷列不可用，则回退到原子序数，再回退到元素符号的大写形式。

## 典型工作流

```
        .gms + .dat  ──dat2molden──▶  .molden
                                          │
                                          │  (可用 Molden/多轨道程序检查、编辑、换基组)
                                          ▼
                       molden2gmsinp  ·  --set 提供路线段
                                          │
                                          ▼
                                        .inp
```

`dat2molden` 产出的 Molden 再喂给 `molden2gmsinp`，基组与轨道系数可以
原样往返（已实测：13 个壳层、31 个基函数、34 个轨道往返一致）。

## 环境

- Python 3.6+
- 仅标准库（`sys`、`os`、`re`、`math`）
- 输入输出均为纯文本，无外部依赖
